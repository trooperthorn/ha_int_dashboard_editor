# Documentation index

One line per document stating what it owns, so a reader knows where a fact belongs.
Code carries only what a reader needs at the point of reading; explanation lives here.

- `design.md`: why Home Assistant cannot edit YAML dashboards, the round-trip through
  a scratch storage dashboard, the reconcile rules, formatting, the dashboards block.
- `security.md`: trust boundary, what is written and where, what the scratch copy
  exposes, what is not defended against.
- `operations.md`: test gate, frontend build, release path, branch protection,
  troubleshooting.
- `decisions.md`: dated decisions with the alternative rejected and why.
- `backlog.md`: dated open items.
